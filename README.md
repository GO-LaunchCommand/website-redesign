# GO Website Redesign

## Setup (first time only)

1. Download and install **GitHub Desktop**: https://desktop.github.com
2. Open GitHub Desktop → **File → Clone repository**
3. Choose **URL** and enter: `https://github.com/GO-LaunchCommand/website-redesign`
4. Pick a folder on your computer to save it (e.g. `Documents/GO-Website`)
5. Click **Clone**
6. Open **Claude Code** → Open Folder → select the cloned folder

## Making changes

1. In Claude Code, ask it to make changes in plain English
2. Open `index.html` in Chrome to preview
3. When happy, go to GitHub Desktop — you'll see your changes listed
4. Add a short description (e.g. "Updated hero copy") and click **Commit to main**
5. Click **Push origin** — Netlify will auto-deploy within seconds

## Before you start editing each session

Always click **Fetch origin** in GitHub Desktop first — this pulls in any changes
the other person has made so you're always working from the latest version.

## Files

- `index.html` — the full website (edit this one)
- `img/` — background images (don't delete)
- Videos are not in GitHub (too large) — keep the Demo Videos folder separately
